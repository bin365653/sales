## 三、API 修改清单

| API | 变更 |
|---|---|
| `POST /api/leads`、`PATCH /api/leads/:id` | 入参新增 20 画像字段 + `verifications`（snake fieldKey→四态，白名单外 400 `verification_field_invalid`）；V1.0 旧状态键（currentSystemStatus 等）保留为别名通道（verifications map 优先）；字典启用字段值域校验（400 `dict_value_invalid`）；同事务写核实行+旧列镜像+重算象限/完善度；值变化自动置 unverified（P2 缺陷修复）、清空置 unknown。 |
| `GET /api/leads/:id` | 返回体新增 `verifications` 五元组数组。 |
| `GET /api/leads` | 筛选参数新增：`quadrant`（a/b/c/d/pending）、`qinceInterest`（yes/no）、`nextGen`（yes/no）、`coreVerified`（yes/no，映射 profile_status basic/deep）、`expiryView`（within_6m/within_1m/expired/unknown）、`expiryMonth`（YYYY-MM）。 |
| `GET/POST /api/settings/dicts/:fieldKey`、`PATCH/DELETE …/:entryId` | 新增：字典读（登录即可读，表单需要）与写（仅管理员，POST/PATCH/DELETE=停用）；改动审计 `dict.entry_created/updated/deactivated`；重复值 409（停用同值复活）。 |
| `POST /api/leads/:id/interactions`、`POST /api/tasks/:id/complete-with-interaction` | 「本次确认」扩展入参：`confirmNextGen/nextGenConfirmed`、`confirmQinceInterest/qinceInterestConfirmed`、`confirmExpiry/expiryMonthConfirmed`（勾选无值 400）；确认即写值+confirmed+元数据+updated 事件；保存后自动重算象限/完善度。 |
| 导入/导出链路 | 上传/映射/预览/确认与模板全量感知新字段与字典校验（行级错误与表单同源）。 |

**内部服务**（单一事实源）：`src/server/services/lead-verifications.ts`（核实写入计算）、`src/server/services/dicts.ts`（字典）、`src/server/services/profile.ts`（象限+完善度重算）、`src/lib/quadrant.ts`（evaluateQuadrant 纯函数）、`src/lib/expiry.ts`（月粒度到期工具）。V1.0 四个旧状态列同事务镜像保留（优先级规则/AI context/详情徽章三处旧读取点不漂移，deprecated 待 V2.x 后期下线）。

## 五、手工验收步骤（建议 15 分钟）

1. **登录** → 工作台首页：四象限分布条可见，点击「待完善」跳转线索池并自动带上筛选。
2. **新建客户**：只填名称保存成功（空值不强迫）；编辑 → 软件画像组选「当前使用软件=舟谱」→ 出现新一代建议条 → 点 [采纳建议] → 保存 → 详情分类卡显示「A·第一象限」+ 依据两行 + 经营建议。
3. **核实闭环**：详情 [记录沟通] → 勾选「是否新一代」「愿意沟通了解勤策」并选值 → 保存 → 画像徽章变绿/蓝、核实历史新增、分类卡「最近变化」出现记录；把「愿意沟通」改为否并确认 → 分类变化 D 类（时间线琥珀点「分类变化」）。
4. **字典管理**（管理员）：设置中心→数据字典→新增一个 current_system 值（如「 testERP 」）→ 客户表单下拉即时出现；停用它 → 新建表单不再出现，历史值不受影响。
5. **字典校验**：把某客户「当前使用软件」手工填一个非字典值 → 保存被拦截且提示中文原因；改成字典值保存成功。
6. **列表筛选**：象限=C + 到期视图=未来 6 个月 组合筛选，与列表结果一致；到期年月选单月核对。
7. **到期年月**：编辑客户到期输入 `2027-06` 保存 → 详情显示「2027-06 · …」；选买断快捷 → 显示「2099-12（买断）」。
8. **权限**：销售账号打开他人客户详情 → 404；设置中心无「数据字典」页签。
9. **移动端 360px**：详情分组展示/记沟通/列表筛选可用，无横向滚动阻断。
