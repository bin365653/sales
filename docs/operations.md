# 操作手册（T18 交付，PRD §10-8/9/10 配套）

> 面向日常使用者（销售 / 管理员）。安装与部署见 README「快速开始」与
> `docs/deploy.md`；指标计算口径见 `docs/metrics.md`；备份恢复操作见 §10。

## 1. 登录与账号

- 系统不开放自助注册：账号由管理员在 **设置中心 → 账号管理** 创建
  （初始密码仅创建时一次性显示，请立即登录并在「账号与密码」中修改）。
- 忘记密码：联系管理员重置（重置后全部已登录会话立即失效）。
- 会话有效期 30 天（滑动续期）；「退出登录」立即失效。
- 登录连续失败 5 次将锁定 15 分钟（按 IP+账号）。

## 2. 工作台（首页）

- 三张今日卡：今日待联系 / 今日任务 / 逾期任务，点击直达对应列表。
- 「本周概览」四项指标整卡跳转数据看板。
- 「建议优先联系」：规则引擎（合同 30 天内到期 → 今日待联系 → 画像完整度高
  且从未联系），每条带推荐理由；点击电话号可复制，系统不会自动外呼。

## 3. 线索池

- 搜索：客户名称 / 联系人 / 电话（电话精确匹配，其余模糊，不区分大小写）。
- 筛选：城市 / 行业 / 来源 / 销售模式 / 在用系统（精确）+ 阶段 / 优先级 /
  负责人（管理员）下拉；筛选条件保留在 URL，可收藏。
- 批量修改仅允许 4 个管理性字段：优先级 / 客户阶段 / 客户来源 / 下次联系时间。
- **导入**（两阶段向导）：下载模板 → 填写 → 上传 → 确认字段映射 →
  预览（有效/错误/重复分栏，逐行可改"新建/跳过"）→ 确认导入。
  - 确认前不写任何客户数据；错误行会给出与表单完全一致的原因。
  - 重复判定：手机号相同 = 确认重复；名称+城市相似 = 疑似重复。
  - 限制：.xlsx / .csv，单次 ≤ 5000 行、≤ 10MB。
- **导出**：列表按当前筛选导出 XLSX；「个人全量导出」输出 ZIP（客户/沟通/
  任务/AI 记录）。导出限速 5 次/小时。

## 4. 客户详情页

- 画像字段按组展示；四个关键事实字段（在用系统/合同到期/采购时间/决策人）
  带核实状态徽标（未知/待核实/已确认）。
- 阶段流转需携带最新版本，他人先改动会提示刷新（409 冲突保护）。
- 时间线：新建/导入/修改/阶段流转全部留痕；阶段流转按当时快照显示
  "从 → 到"，阶段改名不影响历史显示。
- 软删除：删除后不出现在线索池，但历史沟通与统计数据保留
  （"发生过就是发生过"）。

## 5. 沟通记录

- 保存即更新客户"最近联系时间"；方向/是否接通/是否有效为必填。
- **有效沟通**定义：获得有价值业务信息或明确下一步动作，仅接通不算
  （表单内悬停问号可查看）。
- 勾选「形成合格线索」自动推进阶段并写时间线（只进不退）；「预约演示/拜访」
  同理推进。
- **AI 生成摘要**：先在「客户实际反馈」粘贴原始沟通内容 → 点
  「✦ AI 生成摘要」→ 系统回填草稿（紫虚线徽标）→ **人工核对修改后**再保存；
  未确认不会成为正式记录。保存后时间线显示「✦ AI 草稿确认」。
- 修正：记录不可删除，只能修正并留痕（谁、何时、改了什么）。

## 6. 任务

- 类型：首次 contact / 跟进 / 需求诊断 / 在线演示 / 上门拜访 / 报价跟进 / 复活。
- 完成任务弹窗一次事务完成：任务完成（保留完成时间）+ 沟通记录 + 可选
  创建下一步任务。
- 任务只能取消、不能删除；今日视图含逾期置顶（跨自然日才算逾期）。

## 7. AI 功能（管理员配置，全员使用）

- 配置入口：**设置中心 → AI 服务**（仅管理员）：填写 OpenAI 兼容
  Base URL / 模型名 / API Key；密钥加密存储，任何界面只显示尾号四位。
  可保存多套配置、单套激活（换服务商仅需切换配置）。
- 详情页 AI 面板：「✦ AI 客户分析」（8 项分区，区分事实/推断/信息不足）与
  「✦ AI 电话准备卡」（6 项，末项红色警示块）；支持复制、重新生成、查看历史。
  - 输入信息不足时输出"信息不足"，不会编造关键字段。
  - AI 生成约需 10–60 秒，可离开页面稍后在「AI 历史」查看。
  - 每人每日有调用上限（默认 50 次，面板常驻显示今日用量）。
- 被实验分入**常规组**的客户不显示 AI 入口（服务端同步禁止，尝试调用返回
  403 并留审计）。
- AI 失败不影响页面其他功能；提示词模板由管理员在设置中心维护，
  版本只增不改，回滚 = 发布新版本。

## 8. 工时填报

- 设置中心 → 每日工时：周一至周日 7 格，0–24、0.5 步进；每人每日一条，
  重复提交即覆盖。
- 未填报的日期看板「每小时有效沟通」显示"—"（不是 0%）。

## 9. 数据看板与实验

- 看板按周期（今日/本周/本月/自定义）与圈选条件（来源/行业/阶段/负责人）
  计算；口径与"—"规则见 `docs/metrics.md`。
- 实验管理（管理员）：创建实验 → 圈选 + 设定 AI 辅助组占比 → 预览 →
  执行随机分组（分组结果固定不可改）→ 在看板/P8 查看两组对比；样本不足时
  显示"暂不宜判断"。关闭实验即解除常规组禁 AI。
- 操作日志（管理员）：全部关键操作可审计，支持按动作/操作人/日期筛选。

## 10. 数据备份与恢复（管理员/运维）

- 日常备份自动执行（每日 02:00，age 加密，本地 7 份 + 异地 4 周）；失败会
  收到邮件告警。手动备份：`bash scripts/backup/backup.sh`。
- 恢复：`bash scripts/backup/restore.sh <备份文件> --target-db <库名>`
  （带同名防误覆盖保护），恢复后用
  `npx tsx scripts/backup/verify-restore.ts --source <源库URL> --target <恢复库URL>`
  核验。完整核对清单：`scripts/restore-drill.md`；部署侧配置：
  `docs/deploy.md`。
- 注意：模型 API Key 的解密主密钥不在备份中（`.env` 的
  `APP_ENCRYPTION_KEY`），请离线另存；主密钥丢失时业务数据可完整恢复，
  仅需重新录入各模型密钥。
