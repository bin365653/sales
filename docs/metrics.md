# 指标口径手册（T18 交付）

> 看板/工作台/实验对比共用的统计口径。唯一实现：
> `src/server/metrics/`（指标引擎）+ `src/lib/metrics.ts`（周期与比率纯函数），
> 任何界面与 API 均调用同一实现，不做第二套口径。

## 1. 时间口径（决策 C13）

- 一切"日/周/月"均按 **Asia/Shanghai（UTC+8）日历日**判定；
- 周一为一周起点；自然月为月起点；
- 纯日期列（合同到期、工时日期）按 UTC 日期存储、按上海日历日解释；
- 看板周期预设：今日 / 本周 / 本月 / 自定义（起止跨度 ≤ 366 天）。

## 2. 数据范围与圈选

- 权限过滤先于统计：销售 = 本人线索，管理员 = 全量（负责人圈选仅管理员可用）。
- **圈选语义**：先按线索属性（来源/行业/当前阶段/负责人）圈定"同批线索"，
  再对该批线索计算全部指标——不是对各指标分别过滤。
- 工时不挂线索：来源/行业/阶段圈选不改变工时分母；仅"负责人"圈选会收窄
  工时到该负责人。

## 3. 沟通类指标（来源：interactions）

| 指标 | 口径 |
|------|------|
| 呼出数 | 统计周期内 direction=outbound 的沟通次数 |
| 接通数 | 呼出中 connected=true 的次数 |
| 接通率 | 接通数 ÷ 呼出数 |
| 有效沟通数 | effective=true 的沟通次数（**有效 = 获得有价值业务信息或明确下一步动作，仅接通不算**，PRD §5.6，表单文案固化） |
| 有效沟通率 | 有效沟通数 ÷ 接通电话数 |
| 预约数 | demo_booked=true 的次数 |
| 预约转化率 | 预约数 ÷ 有效沟通数 |

- **软删除客户口径**：客户被软删除后，其历史沟通仍计入统计
  （"发生过就是发生过"）；线索池列表不再展示。
- 剔除方向：inbound（呼入）不进呼出/接通分母。

## 4. 阶段类指标（来源：lead_events，K2/C02）

| 指标 | 口径 |
|------|------|
| 合格线索数 | 统计周期内**首次**进入"合格线索"阶段（语义锚点 qualified）的线索数 |
| 合格线索率 | 合格线索数 ÷ 有效沟通数 |
| 演示 / 报价 / 成交数 | 首次进入对应语义锚点阶段（booked_demo / quoted / won）的线索数 |
| 各阶段客户数量 | 当前阶段分布（按语义锚点聚合，改名改码不影响） |

- **首次进入语义**：同一线索多次进出同一阶段只计首次（防止刷数与重复计数）。
- **口径锚定语义锚点**：阶段 UUID + semanticKey 与显示名称解耦——管理员改
  阶段名/编码不破坏历史事件与统计；历史时间线按当时快照显示。
- **同批线索原则**（PRD §5.9）：阶段转化基于同一批线索的推进记录计算，
  不将不同客户批次直接混合宣称"严格转化率"。

## 5. 效率指标

| 指标 | 口径 |
|------|------|
| 每小时有效沟通数 | 有效沟通数 ÷ 实际销售工作小时（工时填报，K5 分母来源） |
| 单条线索平均处理时间 | 线索创建 → 首次合格/关闭的平均时长 |
| AI 使用次数 | 统计周期内 status=success 的 ai_runs 次数（K3：成功才计数） |

## 6. 分母为 0 的显示规则（C03，红线）

- 任何比率的分母为 0、或"每小时有效沟通"缺工时数据时，显示 **"—"**，
  **绝不显示 0%**（0% 会把"没数据"伪装成"表现差"）。
- 界面在"—"处附原因提示（分母 0 / 未填报工时 / 工时为 0）。

## 7. 实验对比口径（T14，PRD §5.10）

- 样本量 = **分组时**组内线索数（固定，不随后续变动）；
- 命中 = 统计周期内达成该指标的**去重线索数**（区别于看板的"事件次数"）；
- 五指标行：有效沟通率 / 合格线索率 / 预约演示率 / 成交率 / AI 使用率，
  与看板同源计算（`computeGroupComparison` 唯一实现，禁止重写口径）；
- 输出仅：比例、绝对差异（pp）、样本量、统计周期；任一组样本量 < 阈值
  （默认 50，实验可配）显示"样本不足，暂不宜判断"；
- **全链路不输出"提升 X%"类因果结论**（V1.0 红线，§5.10）。
